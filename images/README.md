# Evidence

Screenshots that prove each step in `docs/` was performed, grouped by subsystem. Each chapter places its images with a caption stating what the image proves.

| Folder | Subsystem |
|---|---|
| `net/` | Switch ports, VLANs, pfSense interfaces, addressing |
| `fw/` | pfSense rules and aliases |
| `dc/` | Domain controller, Active Directory, DNS |
| `siem/` | Wazuh manager, dashboard and agents |
| `scan/` | SCAN01, Greenbone, the scan identity and its Group Policy |
| `pve/` | Proxmox VE |
| `red/` | KALI01 and the RedTeam segment |
| `sys/` | Windows and Linux endpoints |
| `vpn/` | Tailscale |
| `web/` | biirabank.com and its external security grades |
| `diagrams/` | Architecture diagrams |
| `brand/` | The Biira Bank mark |

Files are named `<area>-<NN>-<subject>.png`, where `NN` is the capture order within the area, so `scan/scan-15-gpo-sec-scanner-access-scope.png` is the fifteenth scanning capture. Files named `image-*.png` belong to the earliest chapters and predate the convention.

Screen recordings are not stored here. They are published on YouTube and linked from the chapter they belong to, with a still frame committed alongside.
