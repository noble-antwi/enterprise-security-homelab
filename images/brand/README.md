# Biira Bank

Biira Bank is the fictional regional bank both lab repositories are built for: this one, the infrastructure and network security estate, and [enterprise-iam-lab](https://github.com/noble-antwi/enterprise-iam-lab), its identity estate. Working to one named organisation keeps the two consistent: one domain, one set of users, one mark.

The mark is a vault door inside a shield. The shield is the protected boundary and the vault door is the controlled way through it, which reads as network segmentation here and as authentication and authorisation in the IAM repository.
